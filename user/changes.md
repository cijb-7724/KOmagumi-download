# 生徒・講師・申込が変わったとき

[← 操作ガイド](README.md) · [保存・PCの移動](files.md)

## まず、何が変わったか選ぶ

| 変更したもの | 更新する場所 |
|---|---|
| 紙の予定だけ変わった | アプリの「生徒」「講師」の○× |
| 休講日・使用コマ・基本期間 | アプリの「開校設定」 |
| 生徒・講師の名簿、既存授業 | 時間割Excel → アプリで「時間割を反映」 |
| 申込数、担当分担、PS1 | 申込Excel → アプリで申込表を読み直す |
| 次の季節の講習になった | 「新規作成」で別の講習を作る |

**同じ講習の更新なら、今の講習を開いたまま更新します。** 新規作成を使うと別の講習になります。

## 生徒・講師が増えた

1. 時間割Excelの名簿・講師欄に追加し、Excelを保存します。両方の冊子で配置したい人は、両方へ登録します。
2. アプリの「入力ファイル」で最新2冊を選び、「時間割を反映」を押します。
3. 「生徒」「講師」に追加した人がいることを確認します。
4. 新しい人の○×を紙から入力します。**名簿に入っただけでは、全日時が○にはなりません。**
5. 申込Excelの「選択肢」にも登録し、担当・申込数・PS1を入力して保存します。
6. アプリで申込Excelを読み直し、「入力を確認」を押します。

申込表にだけ名前を入れても、時間割の名簿へは登録されません。

## 退塾・退職、担当交代があった

新しい授業を追加しない人は、申込や担当・可否を最新の内容にします。名簿の削除・担当交代で、既存授業が自動的に消えたり別の人へ移ったりはしません。

すでに授業がある人については、**先にExcel側で授業と契約を確認**します。中止・担当変更が必要なら職員がExcelを修正し、その最新版を反映します。未消化の申込や授業を残したまま名前だけ削除すると、照合エラーになることがあります。

担当分担は、生徒×科目ごとに最大3人です。講師Aの不足を講師Bへ自動的に振り替えないので、分担が変わったら申込Excelの担当別コマ数も直してください。

## 名前や学年が変わった

時間割Excelと申込Excelの両方を合わせます。申込Excelでは「選択肢」で改名します。数量が同じ人に追従したことを確認して保存し、アプリへ読み直します。

名前・学年の変更では同じ人物と照合できないことがあります。引継ぎの表示と○×を確認し、対応できない人は紙と照合して入力し直します。同姓同名の人の予定を、推測で混ぜないでください。

## 申込数だけ増減した

申込Excelを修正して保存し、アプリで読み直します。**残りコマ数ではなく、契約総数**を入力します。

例：契約10コマのうち6コマを配置済みなら、申込欄は10のままです。追加契約で合計12になったら12へ変更します。アプリが既存の消化を数えて不足分だけを追加します。

契約を減らして既存授業が超過しても、自動削除はしません。レポートの警告を確認してExcelで調整します。

## 時間割を手直しして不足分だけ追加したい

1. 前の結果を保存し、その時間割Excelを職員が修正します。
2. 修正後の2冊を「時間割1」「時間割2」で選びます。
3. 「時間割を反映」を押します。同じ人物・日時の○×は引き継がれます。
4. 申込が変わった場合は、申込Excelも読み直します。
5. 人数、日付、○×、既存授業を確認し、再計算します。

**読み込んだExcelの授業はすべて固定です。** 前の自動生成分も動かさず、今回の不足分だけを追加します。出力前の入力Excelを使う場合は、既存として固定する授業が異なることに注意してください。

同じ講習で時間割だけを差し替える場合、○×を全員分打ち直す必要はありません。新しく増えた人物・日時は別途確認します。
