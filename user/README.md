## いつもの流れ

**講習を開く → 最新Excelを反映 → 紙の○×を入力 → 入力を確認 → 時間割を作成 → Excel3冊を保存**

○×は自動保存されます。**出来上がった時間割は、最後にExcelとして保存してください。**

次回の講習は「新規作成」で別の講習を作ります。前の講習を使い回して名前だけ変えないでください。
