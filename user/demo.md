# デモで試す

[← 操作ガイド](README.md) · [本番の入力を始める →](start.md)

**画面写真と同じ架空データで、読み込みからExcel保存まで試せます。** 紙の予定や実際の名簿の準備は不要です。

## 1. ダウンロードして解凍する

**[練習用データ一式（KOmagumi-demo.zip）をダウンロード](https://github.com/cijb-7724/KOmagumi-download/raw/refs/heads/main/demo/KOmagumi-demo.zip)**

保存したZIPを右クリックして「すべて展開」を選びます。展開先の `KOmagumi-demo` フォルダーに、次の5個があれば準備完了です。ZIPの中から直接開かず、展開したファイルを使ってください。

| ファイル | 内容 |
|---|---|
| 練習用.komagumi | 記入済みの生徒・講師・教室の○×と設定 |
| 時間割1.xlsx | 8月17〜18日。生徒Aの通常授業が1コマ入っています |
| 時間割2.xlsx | 8月19〜20日。追加する前の時間割 |
| 講習申込.xlsm | 生徒A：数学2コマ、講師X。生徒B：英語1コマ、講師Y、PS1 |
| はじめに.txt | 同梱の短い操作手順 |

生徒は中1の生徒A/B、講師は講師X/Yだけです。日付は2026年の4日間です。過去の日付でも試せます。

## 2. 練習用の講習を開く

KOmagumiを起動します。まだ導入していなければ [インストール手順](start.md#1-インストールする)を先に進めてください。

「.komagumi を開く」を押し、展開先の **練習用.komagumi** を選びます。画面上部が「操作ガイド用（架空データ）」になれば開けています。

![起動時の講習ファイル画面。「.komagumi を開く」から練習用を選びます](../assets/screenshots/01-start.jpg)

すでに別の講習を開いている場合は、上部の「講習を選ぶ」から同じ画面に進みます。開いている講習のデータは残ります。

## 3. Excel3冊を読み込む

「コマ組」→「入力ファイル」を開きます。

1. 「時間割1」で、展開先の **時間割1.xlsx** を選びます。
2. 「時間割2」で、**時間割2.xlsx** を選びます。
3. 「**時間割を反映**」を押します。
4. 「申込表（担当・コマ数）」で、**講習申込.xlsm** を選びます。
5. **生徒2人・講師2人・申込3コマ**になったことを確認します。

![時間割2冊と申込表を読み込んだ画面](../assets/screenshots/02-files.jpg)

このデモを計算するだけなら、Excelを開いたりマクロを実行したりする必要はありません。申込の名簿をExcelで編集するときは、テンプレートのマクロを使います。

## 4. ○×を見てみる

「生徒」で生徒Aを選びます。8月17日の3コマに 「**通常**」があり、新しい授業を重ねられないことが分かります。「講師」では同じ日時が 「**+1**」です。講師Xは既存の生徒1人を受け持っているので、追加できる人数は1人です。

![生徒Aの可否表。8月17日の3コマに通常授業があります](../assets/screenshots/04-student.jpg)

ほかの開校枠は○を入力済みです。まずは変更せずに次へ進めます。操作を試す場合は、セルや範囲を選んで×にし、「1つ前の状態に戻す」で戻せます。

## 5. 時間割を作る

「コマ組」へ戻り、「入力を確認」→「時間割を作成」と進みます。計算上限は **10秒**に設定済みです。小さなデータなので、上限より早く完了することがあります。

**申込3・配置3・未配置0**を確認してください。画面写真の総合評価は **0.7780**です。配置位置や点数は、設定やアプリの版によって変わることがあります。0.9や1.0まで待つ必要はありません。

![デモの配置数と総合評価の推移。非常に短時間で完了しています](../assets/screenshots/08-graphs.jpg)

このデモでは探索が短いため、途中停止する前に完了する場合があります。通常の講習では [グラフの見方・止めどき](run.md#stop)を参照してください。

## 6. 結果を保存して開く

「**保存先を選んでExcel3冊を保存**」を押し、新しく作った「デモ結果」フォルダーを選びます。

![申込3・配置3・未配置0と、Excel3冊を保存するボタン](../assets/screenshots/09-save.jpg)

保存された時間割2冊と配置レポートを開きます。**もとの通常授業1コマが残り、「講」で始まる授業が合計3コマ増えている**ことを確認します。元の入力Excelは変わりません。

○×を変更したら上部が「自動保存済み」になってから閉じます。同じ `練習用.komagumi` を開けば続きを試せます。最初の○×に戻してやり直す場合は、ZIPを**別のフォルダーへ**もう一度展開してください。

本番は「新規作成」で別の講習を作ります。デモの名前だけ変えて本番に使い回さないでください。
