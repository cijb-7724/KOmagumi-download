## 技術選定

Windows x64 / Python 3.12 / OR-Tools CP-SAT / HTML・JavaScript / pywebview・WebView2。PyInstaller onefileでPythonとライブラリを内包し、NSISセットアップが必要時に公式WebView2を導入します。外部サーバーとSQLiteは使いません。

[第三者の構成物と出典](THIRD_PARTY.md)。依存物のライセンス通知は配布アプリ内にも含まれます。

## 仕様を見るときの注意

「配置上限に到達」「総合評価の最適性を証明」「グラフが横ばい」「職場で受入済み」はそれぞれ別の状態です。点数0.9や長時間探索だけで、最適性や実運用上の無不具合を主張しません。
