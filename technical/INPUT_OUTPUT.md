# 入力・保存・入出力の契約

[← 技術資料](README.md) · [職員向けの保存説明](../user/files.md)

## 情報の正本

| 情報 | 正本 |
|---|---|
| 名簿・日時・既存授業・セル位置 | 実行時に読み込んだ時間割Excel2冊 |
| 担当別契約総数・PS1 | 講習申込Excel |
| 個人○×・開校・設定・メモ | .komagumi |
| 確定結果・評価・推移 | 外部に保存するExcel3冊 |

内部の古いsnapshotや前回結果を、最新Excelの既存授業へ混ぜない。

## 時間割の書式

授業元は「講習スケジュール(入力用)」、生徒名簿は「学年と名前を結合するシート」。生徒スケジュール・講師用は表示帳票。生徒セル左・科目セル右の対を1枠として扱い、各講師上下2枠を検証する。

現帳票は日付D2から14列刻み、コマ時刻3行目、講師B4/B6…、名簿A学年/C氏名/D表示名等。ただし毎回構造を検査し、ファイル名や過去の行数から書込先を推測しない。数式、結合、補助計算、未解決枠を空欄と誤認しない。

「講」始まりを講習として消化対象にする。通常・振・追・体験等は固定だが講習へ換算しない。MTMG・事務・時刻だけの予定は該当講師・コマへの追加を止め、授業・ブースへは数えない。

## 申込の書式

標準は .xlsm。「講習申込」「選択肢」「PS1対象」の3シート。1行目が一意の列名、A学年/B生徒氏名、英数国理社それぞれ担当・申込を並べる。最大3担当拡張は担当1/申込1〜担当3/申込3。旧1担当・旧8月5日書式は互換入力。

数量は非負整数の契約総数。正の数量には有効な担当が必須。同科目の同担当重複、数量の数式・負数・小数はエラー。PS1は生徒×科目で指定し、太字や色から推測しない。

「選択肢」はtblStudents/tblTeachers、申込はtblApplications、PS1はtblPS1。マクロが非表示の安定IDで改名・挿入・並べ替えに追従する。正の申込がある削除対象を自動で消さない。配布テンプレートは仮名のみ。

## 人物と引継ぎ

人物は内部ID、学年、氏名、添え字、原本行を持つ。原本行やファイル指紋だけを人物の恒久IDにしない。同じ講習のExcel差替えでは、確認できる人物・日時・コマの○×と設定を維持し、新しい既存授業を読み直す。新人物・新日時は初期値、曖昧な一致は推測せず通知する。

新規の省略値は生徒×、講師は既存授業あり○・それ以外×。個人可否と授業占有、既存欠席、教室休講は分けて保持する。旧JSONの既定値は旧形式の意味で展開し、新規初期値で上書きしない。

## .komagumi

`courseSettings.newPlacementAfter`は新規配置の基準日で、厳密なYYYY-MM-DDまたは空文字。省略時も制限なし。コマ組で編集し、指定日当日を除いた翌日以降へだけ追加する。既存授業の消化・占有・評価を切り捨てない。可否と一緒に保存・移動・Excel差替え・Undo/Redoで保持し、レポートにも基準日を記録する。

SHA付きのコンテナ。人物・日時の対応、全可否、既存欠席、メモ、NG、期間、使用コマ、重み、直近10操作を保存する。**暗号化ではない**ため、人物や予定の保護は利用先のファイル管理で行う。

Excel本体、既存/新規授業明細、申込数量、PS1、生成結果、探索ログは格納しない。別PCでは時間割と申込を再接続する。同じPCでは内部作業コピーを再利用できる。

## 内部保存と結果

`%LOCALAPPDATA%/KOmagumi/courses` に原子的JSONとExcel作業コピーを置く。UIにJSON操作や内部安全コピー一覧を出さない。OSの講習ロック、revision照合、同一プロセスのロックを使い、古い画面の書込を拒否する。

文書保存は直前のSHAを照合して一時ファイルから置換する。外部変更・移動・削除なら上書きせず、内部入力から別名保存できる。Undo/Redo合計10操作・10MiB、内部安全コピー30時点以内。利用者の外部Excelや講習を容量整理で消さない。

完成結果は入力と独立して保持する。次の正常結果を確定してから最新を置換する。入力確認、秒数変更、計算開始・失敗では削除しない。新規登録の内部結果とチェックポイントは最新2回まで。指紋が変わったコピーや未登録の外部ファイルは整理対象外。

出力はOOXMLへの限定追記で、元セル・VBA・数式・書式等を保持する。独立した制約検証と原本保持検証に成功してから公開する。
