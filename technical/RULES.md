# 業務ルールの要約

[← 技術資料](README.md) · [数理モデル](MATHEMATICAL_MODEL.md)

配布版v0.9.0の仕様要約。変更作業では、アクセス可能な開発リポジトリの `REQUIREMENTS.md` と付属定義を正本にする。

## 固定と追加

実行時の時間割Excel2冊を固定事実とし、通常・振替・追加・体験・既存講習・前回生成分・手修正を移動、削除、担当変更しない。変数は新規講習の追加だけ。新規は90分・1コマ単位。

担当別契約総数をR、採用した既存講習をEとし、担当別追加上限は `max(0,R−E)`。担当外授業を含む科目の既存総数でも追加上限を制限する。最大3担当は事前指定で、solverが担当を選択・振替しない。

## 新規配置に必須の条件

| 条件 | 内容 |
|---|---|
| 名簿と日時 | 人物が書込先の冊子に存在。実際の空欄セルがある |
| 期間 | 中学生は基本期間内、小学生・高校生はExcel全表示期間。期間外減点なし |
| 個人と教室 | 生徒○、担当講師○、教室開校、使用対象コマ |
| 占有 | 生徒は同時刻1授業。講師は最大2人 |
| PS1 | 生徒×科目の1対1契約。同じ講師・コマへの同席なし |
| 生徒日上限 | 全種別の既存を含め5コマ以下 |
| 生徒連続 | 帳票のコマ順で4連続以下。休憩時刻で分断しない |
| ブース | 授業中の異なる講師を最大10人。出勤○だけなら使用に数えない |

同じ科目の同日複数回、異学年・異科目の1対2を禁止しない。講師の日上限・連続上限は追加しない。NG生徒ペアはソフト条件で、同じ講師の1対2同席だけを数える。

## 既存例外

既存の6コマ以上・5連続以上・11ブース以上・PS1同席等は保持して警告し、それだけで全体を実行不能にしない。新規で超過を作ったり延長したりしない。既存11ブースでも、すでに授業中の講師の空席へ2人目を加えることは他条件を満たせば可能。

生徒同時刻重複は、入力シート上段の授業を契約消化・生徒評価に採用し、原本の全セルを保持する。講師定員・ブースは物理占有を数える。担当不明等、安全な読取ができないものは入力エラーとする。

## 目的と出力

比較は **配置総数 → 同数なら9項目の重み付き同時評価**。0コマ人数は表示するが独立した上位目的にはしない。全件配置をハード条件にせず、未配置があっても有効な結果と理由を出す。

既存＋新規の合計を採点し、既存を動かさず追加位置を改善する。出力は既存を保持した時間割2冊とレポート1冊。独立検証に成功した結果だけを確定する。
