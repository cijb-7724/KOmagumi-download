# 配置の比較・評価の定義

本書は要件定義書第9・10節の付属定義。方針は `combined-schedule-v8`。固定の既存授業と新規配置を合わせて評価し、既存授業は動かさない。小学生・高校生の基本期間外減点はない。契約消化と既存の重複採用はINPUT_OUTPUT.mdに従う。

## 比較順と重み

比較順は（契約消化総数、総合評価）。固定消化は同一入力で定数なので、新規配置1コマ増を全ソフト変化より優先する。0コマ人数は参考表示。

| 項目 | 初期重み |
|---|---:|
| 講師空き | 14 |
| 1対2 | 9 |
| NG同席 | 8 |
| 生徒空き | 6 |
| 実施日数 | 5 |
| 期間分散 | 4 |
| 間隔均等 | 3 |
| 充足率 | 2 |
| 早い時間帯 | 1 |

良いほど大きい0〜1値の重み付き平均。項目間の辞書式順位ではない。重みは講習ごとに0〜100の整数で編集・保存し、降順（同値は安定順）で表示。0は目的と平均分母から除く。全0または全項目対象外なら配置数だけを最大化し、総合点は対象なし。適用対象と正規化分母は入力で固定し、先行解・候補数で変えない。

v7とv8の利用者編集値を保持する。編集不可だった旧v1〜v6は初期値へ読み替える。旧ファイルを開くだけで書き換えない。旧結果は以前の評価方式と明示し、現在の式・重みで計算した結果に見せない。

## 充足率・1対2・NG

充足率は生徒ごとの担当別契約消化（既存＋新規、担当別申込を上限）÷申込合計。正の申込がある生徒を均等平均。

B2は非PS1の固定授業数＋非PS1の担当別追加残数。既存＋新規の2人授業（PS1なし）に入る延べ生徒コマ数Jを使い、1対2点=J/B2。既存のみ・既存＋新規・新規2人のいずれも1組2生徒コマ。B2=0は対象外。画面の実測は組数。

NGは同じ講師・日時の2人授業のみ。既存だけを含め1件あたり2生徒コマの負担Gとして、NG点=1−G/B2。NG未登録またはB2=0は対象外。画面の実測は発生件数。既存3人以上やPS1同席は別途警告し、2人授業の得点に混ぜない。

## 講習の日数・分散・間隔

正の申込がある生徒×科目を対象にする。Rは申込合計、Fは採用済み既存講習数（新規対象日外を含む）、Uは科目追加可能数。固定基準量Q=max(R,F+U)。評価日集合は新規配置対象日と、その科目の既存講習日の和集合。dはその日数、Wは最終日−初日の暦日数。新規対象日は中学生が基本期間内、小学生・高校生がExcel全表示日、学年不明の旧人物は基本期間＋本人の追加期間。

Aは既存＋新規講習の実施日集合。同日複数回で日数を増やさず、全担当・両Excelを科目ごとにまとめる。

- 日数点=|A|/min(Q,d)。
- 分散点はQ≥2かつW>0で適用。(最終日−初回日)/W。0〜1実施日なら0。
- 間隔点はQ≥3かつW>0で適用。3実施日以上なら隣接暦日間隔hから1−(max(h)−min(h))/W。3日未満なら0。

科目を生徒内で均等平均してから生徒間で均等平均する。通常授業等を講習日数に換算しない。

## 空き

通常・振替・追加・体験・講習を含む全既存＋新規を、Excel全表示期間で数える。人物×日の占有コマ順集合Tに対し、無授業なら0、それ以外はmax(T)−min(T)+1−|T|。最初より前・最後より後を含めない。重複占有は1コマ。延べ空きをHとする。

人物の基準量Bは既存の異なる占有コマ数＋担当別追加残数。生徒は集計採用済み授業、講師は物理占有を使う。全コマ数p（0コマを含む）・Excel日数dからHmax=max(0,p−2)×min(d,floor(B/2))。人物点=1−H/Hmax。Hmax=0は対象外。人物均等平均。

サマリー・評価・グラフ・人物日別内訳の結果の空きは同じHの合計。既存のみの空きを比較基準に併記し、既存と新規の間の空きも評価へ含める。

## 早さ

使用コマの先頭・末尾順をi0/i1とする。i0=i1なら早さ1、それ以外は1−clamp((i−i0)/(i1−i0),0,1)。生徒ごとに採用済み全既存＋新規授業の早さ合計を上記Bで割り、人物均等平均する。未配置に点を与えない。

## 整数精度と配置最優先

尺度は1,000,000。末端点と科目→人物・人物間の平均は各段階でfloor。CP-SAT・画面・レポート・最良保存が同じ整数点を使う。適用重み合計w、M=尺度×w、A=M+1として目的はA×新規配置数＋Σ(重み×整数点)。全件配置をハード条件にしない。

配置上限は生徒別最大流とsolver上界の小さい方。緩和した上界の達成可能性を断定しない。配置数と総合評価の証明を分け、横ばいを最適と断定しない。動作確認で長時間探索しない。

## グラフ

配置数・総合評価と9項目を同時表示。縦軸は実測範囲へ余白を加えて調整し、Excelレポートも同様。総合点・早さは点、配置数・空きはコマ、1対2は組、NGは件、日数・期間・間隔は日、充足率は％。横軸は秒。異なる単位を同じ軸に重ねない。

各実解は `preference_points` と測定済み `preference_values` を保持。配置数先行段階のソフト値と起動時の仮0を実測へ混ぜない。旧記録に途中実数がなければ逆算せず、測定済み最終値の1点のみを使う。旧方式であることを明示する。
